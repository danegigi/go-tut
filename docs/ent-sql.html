Ent Tutorial (Basic → Intermedia)


1. Introduction

Ent is a code-first ORM for Go. You define schemas in Go and Ent generates a type-safe API.

Schema
  ↓
go generate ./ent
  ↓
Generated Client
  ↓
CRUD
  ↓
SQL

https://entgo.io/docs/getting-started/

https://github.com/ent/ent/tree/master/examples/start

2. Database Connection

SQLite

client, err := ent.Open("sqlite3", "file:ent.db?_fk=1")

No SQL equivalent exists because connections are handled by the driver.

Run development migration:

client.Schema.Create(ctx)

https://entgo.io/docs/dialects

https://entgo.io/docs/sql-integration

3. Schema Definition

A schema defines an entity.

type User struct {
    ent.Schema
}

A schema contains:

  • Fields
  • Edges
  • Indexes
  • Mixins
  • Annotations

5. CRUD Operations

Create

client.User.Create().
 SetName("John").
 SetEmail("john@example.com").
 Save(ctx)
INSERT INTO users(name,email)
VALUES('John','john@example.com');

Read

client.User.Query().
Where(user.Email("john@example.com")).
Only(ctx)
SELECT *
FROM users
WHERE email=?
LIMIT 1;

Update

client.User.UpdateOneID(id).
SetName("Jane").
Save(ctx)
UPDATE users
SET name='Jane'
WHERE id=?;

Delete

client.User.DeleteOneID(id).Exec(ctx)
DELETE FROM users
WHERE id=?;

Transaction

tx,_:=client.Tx(ctx)
// operations
tx.Commit()
BEGIN;
...
COMMIT;

6. Query Builder

Filtering:

client.User.Query().
Where(user.And(
 user.AgeGT(18),
 user.NameContains("John"),
))
SELECT *
FROM users
WHERE age>18
AND name LIKE '%John%';

Ordering

Order(ent.Desc(user.FieldName))

ORDER BY name DESC;

Aggregation

Count()
GroupBy()
SELECT COUNT(*) FROM users;

7. Pagination

Query().Limit(10).Offset(20)
SELECT *
FROM users
LIMIT 10 OFFSET 20;

Cursor pagination is recommended for large datasets.

https://entgo.io/docs/paging

8. Eager Loading

client.User.Query().
WithPosts().
All(ctx)
SELECT u.*, p.*
FROM users u
LEFT JOIN posts p
ON p.user_id=u.id;

Soft delete

Instead of

DELETE FROM users;

Use

UPDATE users
SET deleted_at=NOW();

Common hooks:

  • Validation
  • Audit logging
  • Password hashing
  • Soft delete
  • Timestamp updates
